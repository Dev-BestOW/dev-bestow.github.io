# dev-bestow.github.io

Dev-BestOW 조직의 GitHub Pages 루트(호스트 단위) 사이트예요.

- `index.html` — 루트로 온 사람·검색 엔진을 [BestOW UI 소개 사이트](https://dev-bestow.github.io/BestOW-UI/)로 보내요.
- `robots.txt` — 호스트 루트에서만 읽혀요. sitemap 위치를 알려 줘요.
- `naver*.html` — 네이버 서치어드바이저 소유 확인 파일. **지우면 확인이 풀려요.**
- `.nojekyll` — Jekyll 처리 끄기.

실제 사이트는 [Dev-BestOW/BestOW-UI](https://github.com/Dev-BestOW/BestOW-UI) 저장소가 `/BestOW-UI/` 경로에 배포해요.
이 저장소에 `BestOW-UI` 폴더를 만들지 마세요(경로가 겹쳐요).
